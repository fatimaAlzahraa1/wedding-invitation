# Wedding Invitation Demo

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit `app/page.tsx`:
- Names: Ahmed & Sara
- Wedding date/time
- Venue
- Google Maps URL
- Timeline
- RSVP text

Edit `app/globals.css`:
- Colors
- Fonts
- Spacing
- Background images

The demo uses remote Unsplash images. For a production invitation, download/own your images and place them in `public/images`, then replace the URLs in CSS.
